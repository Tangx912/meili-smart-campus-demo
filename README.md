# 梅李镇特色产业中心 · 智慧园区演示

基于项目提供的CAD与照片制作的Three.js浏览器演示，包含11栋建筑、11号综合楼精细模型、六层公共空间与房间分区，以及园区咨询助手“梅李小智”。

## 展示与交互

- 深色大屏、方形模型底板、边界/屋顶/通道轻量发光。无虚拟城市路网或农田。
- 园区总平面、主入口名牌、公共通道及11号楼四个正立面。立面保留整个地块设施，仅隐藏其他10栋主楼。
- 双击11号楼进入选层界面，悬停立面或右侧按钮预览高亮切片，点击进入楼层；条形菜单同样可选层。
- 楼层仅显示1.1m抽象墙体及完整直角功能色块，含边界线，无家具。鼠标移入房间点亮并显示名称，移开熄灭；触屏可轻点查看。
- 六维知识每类一张可点击的轻量虚拟示例卡。所有示例企业、人物和经济数字明确标注虚拟，不代表实际入驻或经营数据。
- 小智回答区占卡片60%以上；输入框内话筒可发起浏览器语音识别，回答可播报。首次使用需允许麦克风；识别可能依赖浏览器网络服务，不保证所有浏览器支持。
- 本地诉求记录只保存于当前浏览器，不向物业发送，不是正式工单。

当前问答使用本地项目资料与规则，未连接外部大模型。语音使用系统音色，已优先选择可用中文音色并放慢语速；更自然的云端神经语音需要单独的后端服务，不能把密钥放入公开前端。

## 机器人巡检演示

默认展示闭合巡检流线、沿线移动机器人、流动光带与雷达扫描。底部面板可暂停、重置、打开巡检视角或跟随机器人。进入楼层/11号楼精看时自动隐藏巡检展示。路线仅用于展示，不是实际机器人导航或真实巡检状态。

## 本地运行

需要Node.js 20+：

```sh
npm ci
npm start
```

打开 http://127.0.0.1:4186/ 。macOS也可双击“启动园区.command”。端口冲突时使用`PORT=4187 npm start`。

## 测试与静态部署

```sh
npm test
npm run build
```

`dist/`为完整静态发布目录，包含运行所需Three.js文件与`.nojekyll`，无需在线CDN，可用于GitHub Pages。应用使用相对路径，可部署到项目子路径。

公开源代码在`main`分支；静态站点在`gh-pages`分支。更新代码后重新构建，将`dist/`内容同步至`gh-pages`即可更新页面。

## 修改入口

- `src/main.js`：机位、建筑显隐、楼层与场景交互。
- `src/dashboard.css`：大屏布局、配色、问答卡片比例。
- `src/demo-knowledge.js`：六维虚拟示例，保持轻量即可。
- `src/campus-knowledge.js`：本地回答、定位动作。
- `src/voice.js`：语音识别与系统播报。
- `src/scene-effects.js`：边界、屋顶与通道光效。
- `data/building11-floors.json`：CAD空间数据和直角展示分区；`displayPolygons`为交互示意，非测绘面积。

详细说明见[大屏与扩展接口](docs/SMART_SCREEN.md)、[几何来源](docs/SOURCES.md)、[11号楼细节](docs/building11/DETAILS.md)。

## 公开范围与限制

此仓库只备份应用源码、运行需要的派生几何数据与示例资产。原始DWG、现场照片、CAD转换中间文件、个人文件和密钥不公开。这些原始资料仅保存在项目拥有者本机；公开仓库无法独立重新解析原始CAD，但可直接运行已交付模型。

场景用于演示，公共连廊和景观有简化，不提供BIM或工程测量精度。Three.js等依赖许可见[第三方说明](THIRD_PARTY_NOTICES.md)。
