# 大屏与小智接入说明

运行方式和公开部署见根目录README。

## 当前展示

深蓝青色大屏，方形底板，边界、屋顶和通道有少量轮廓光效。左/右信息面板上下对齐，左侧车位为“园区车位189”。11号楼立面模式保留整个场地（道路、停车、绿化、围墙、名牌和配套设施），只隐藏其他主楼。选层界面则独立显示11号楼与选层卡片。

选层大菜单在上，小工具条在下；右侧选层卡片与大菜单顶部对齐。鼠标悬停楼层高亮切片与边框，点击拆出楼层。功能色块按CAD墙轴与原房间区域投票生成直角分区，完整覆盖楼板并画出边界。原始房间轮廓仍在polygons，展示使用displayPolygons；不作为工程面积依据。

房间名称不带虚拟企业后缀。鼠标移入房间高亮并显示名称，移开自动清除，触屏可轻点。

## 六维虚拟示例

src/demo-knowledge.js每类只有一张卡：企业、空间、人物、产业、经济、服务。均标注虚拟演示，经济数字不是实际经营数据。空间示例可定位11号综合楼二层物业办公。

## 小智和语音

回答区在桌面和手机均至少占卡片60%。话筒位于输入框内部；取消单独语音提问栏与最新回答重播按钮，保留回答播报开关。

浏览器Web Speech接口无需前端密钥，但语音识别可能需要浏览器厂商网络服务及HTTPS（localhost可用）。用户需允许麦克风；不支持或拒绝时可继续文字提问。系统音色优先选择可用的中文自然音色，语速0.94，长回答按标点读取；不承诺真人音色或离线识别。关闭卡片会取消识别与播报。

## 外部服务接口

`window.meili.setAssistantProvider(async(question,context)=>({text,actions,card}))`可接后端问答。

- actions可含floor（1—6或all）、room（空间ID）、view（既有机位）、service（services/requests）。
- card结构为`{title,tag,fields:[[字段名,字段值],…]}`，全部使用textContent展示。
- GLB骨骼扩展接口仍保留为`meili.loadAvatar(url,options)`，不作为主要前台助手。
- 正式大模型和云端神经语音的密钥应放在后端，不得提交到公开仓库。

诉求存储键为meili-local-requests-v1，仅当前浏览器可见，刷新保留但不能跨设备同步，不代表物业已受理。真实政策库、工商数据、活动报名、人工预约、经济数据、工单流转和硬件灯控未连接。

## 验证

npm test检查CAD尺度、六维示例和六层直角分区；scripts/check-presentation.mjs检查菜单对齐、回答占比、六维点击和话筒位置；scripts/check-hover-site.mjs检查完整场地显隐、菜单顺序、切片和房间悬停；scripts/check-voice.mjs用模拟接口检查语音流程（不代替真实设备试音）。

## 巡检流线演示

src/patrol.js定义园区内部闭合流线与程序化轮式机器人，包含流动光带、扫描扇面、雷达环和移动转向动画。UI支持暂停/继续、重置、巡检总览、跟随；手动拖动相机退出跟随。路线按展示速度运行，不连接真实机器人、告警或传感器。楼层与11号楼单体观察时隐藏，避免干扰。
